### Task 1: Data Collection and Emulation

This directory contains the Python script **`synthet_ads_mmp.py`**, which generates three CSV files:

- **`ads_google_ads_last_14_days.csv`** — Synthetic data for Google Ads
- **`ads_facebook_ads_last_14_days.csv`** — Synthetic data for Facebook Ads
- **`mmp_last_14_days.csv`** — Aggregated data from an MMP (Adjust/AppsFlyer)

### How to Run

1. Make sure you have **Python 3** and **VS Code** installed.
2. Open the `synthet_ads_mmp.py` file in VS Code (`File → Open File`).
3. Run the script via **Run and Debug**.
4. The generated CSV files will be saved in the same folder where the script is located.
